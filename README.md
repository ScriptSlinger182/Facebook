## 一、基础架构搭建
### 1. 账号与工具准备
- **创建企业认证主页**  
  优先选用「带粉老主页」（1000粉成本约$8）提升可信度，主页需垂直领域明确（如家居/服饰/3C），建议购买「蓝勾认证主页」增强用户信任。
- **开通Facebook Shop功能**  
  需绑定企业BM账号，支持产品目录自动同步独立站商品（Shopyy/SHOPAiMi等平台可一键导入），设置短信最大化购买功能优化转化路径。
